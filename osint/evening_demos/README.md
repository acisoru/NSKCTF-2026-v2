## Описание

Из накладной участник узнаёт о фотодневнике наблюдений сотрудника mr. Fade. На странице находится целевое фото Луны, снятое через телескоп-рефлектор. Цель — опознать отмеченный кратер, найти, в честь кого он назван, и собрать флаг из названия и проверяемого числа.

## Решение

Коротко: **накладная → поиск фотодневника по нику → фото Луны → опознание кратера Fracastorius → год смерти учёного, в чью честь назван кратер (1553) → флаг.**

1. **Накладная** указывает на сотрудника mr. Fade, его хобби — фотодневник наблюдений — и ник `fade-evening-demos`. По нику поиском в GitHub находится профиль и его публичный репозиторий.
2. **Фотодневник** содержит семь снимков с лорными подписями; целевой — фото Луны с подписью «последний показ» и перекрестием на кратере.
3. **Фото снято через телескоп-рефлектор** — повёрнуто на 180°. EXIF вычищен, кадр обработан, прямой reverse-image-поиск не находит оригинал. Первый шаг — развернуть кадр.
4. **Опознание кратера.** Главная зацепка — длинная извилистая борозда на затопленном дне, плюс дуга вала. По этим признакам в открытом атласе (LROC QuickMap, Virtual Moon Atlas) кратер опознаётся как **Fracastorius**.
5. **Год смерти.** Кратер назван в честь итальянского учёного Джироламо Фракасторо. Год его смерти — **1553**.

Полный разбор по шагам — в [solve/solution.md](solve/solution.md). Скрипт обработки снимка — в [src/make_moon.py](src/make_moon.py).

## Флаг

`nskctf{fracastorius_1553}`
