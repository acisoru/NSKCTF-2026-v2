> http://<ip>:3388/?level=easy

## Деплой

Исходники для разработки находятся в `src/`. Каталог `deploy/` содержит
копию `src/`, Dockerfile, Compose-файлы и `.env`; он собирается автономно.
После изменения исходников выполните `./deploy/sync-src.sh` из каталога
задачи, затем запускайте Compose из `deploy/`.

Из корня репозитория:

```sh
cd admin/network_ops/deploy
docker compose up
```
