# Файлы Алисы | Medium | forensic

## Информация

> Из архивного пункта комиссии по ревизии Лаборатории X утёк
> конфиденциальный доклад. Восемь страниц о пропавших сутках, ALICE
> и внутреннем вмешательстве оказались у внешней редакции.
>
> Установите, кто выпустил этот экземпляр и в какую минуту он был
> напечатан.
>
> Формат: `nskctf{surname_HHMM}`. Фамилия латиницей приведена в журнале;
> время - местное время Новосибирска, четыре цифры.


## Деплой

Сервер не нужен. Готовый PDF уже находится в `public/`.
`deploy/` содержит необязательный контейнер сборки, который завершается
после генерации. Сетевых сервисов и портов нет.

```sh
cd forensic/alice_files/deploy
docker compose run --build --rm yellow_dots_builder
```

Локальная пересборка и проверка из корня репозитория, Python 3.14:

```sh
python3 -m venv /tmp/yellow-dots-venv
/tmp/yellow-dots-venv/bin/pip install -r forensic/alice_files/requirements.txt
/tmp/yellow-dots-venv/bin/python forensic/alice_files/src/build.py
/tmp/yellow-dots-venv/bin/python forensic/alice_files/solve/solve.py \
  forensic/alice_files/public/scan_03.pdf --all-pages
/tmp/yellow-dots-venv/bin/python -m unittest discover \
  -s forensic/alice_files/solve -p 'test_*.py' -v
```

Размер PDF около 21,4 МиБ. Сборка требует до 2 ГБ памяти.
Seed по умолчанию `20260917`; зависимости и шрифты закреплены.
Для изменения сканирования есть `--seed`. После изменений проверяйте
все страницы. Байтовая идентичность между платформами не гарантируется.

## Описание

Синтетический Machine Identification Code по опубликованной EFF схеме Xerox
DocuColor: 15 столбцов, 8 строк, 7 бит на значение, BCD-серийник и нечётная
чётность. Верхняя строка в целом чётная; строки данных и все столбцы нечётные.
Повторения со сдвигом позволяют восстановить точки, повреждённые шумом,
текстом, пропусками тонера или JPEG. Это программно созданный образец.

Сохранены параметры выбранного `scan_03`: серийник 00483729,
время 16.09.2026 20:06 UTC и характер сканирования с поворотом около 0,41°.
Другие копии исключены из выдачи. Данные печати на всех восьми листах одинаковые.

[Доклад](src/confidential_report.md) занимает восемь полных страниц, около
4700 слов, и основан на `LEGEND.md`. Календарная арифметика, ограничения
ALICE и правила канона сохранены; поздние сюжетные раскрытия не включены.
Содержание доклада полностью сюжетное: жизнь отделения, инцидент, пробел,
наблюдение ALICE, возвращение исследователей, HACKED, карантин и ожидание ревизии.
Советов по обработке изображений и сопоставлению печати с проходами в нём нет.
Технический персонал в приложении отделён от исторических исследователей.

Журнал занимает три полных листа по 46 строк. Минута печати не появляется
в открытых отметках. Дополнительные проходы увеличивают число кандидатов,
но не гарантируют защиту от перебора: на платформе нужен лимит попыток сдачи.
