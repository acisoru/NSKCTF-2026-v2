## Описание

В `src/web/` находятся HTTP-сервер и интерфейс, в `src/orchestra-listener/`
исходники C3-бинаря. Модули `abc`, `score` и `vm` отвечают за разбор ABC,
проверку партитуры и исполнение. Партитура и состояние VM передаются явно.

Orchestra — стенд mr. S для проверки аварийных протоколов Лаборатории X.
Несколько контуров исполняют действия, записанные музыкальными партиями.
В найденной партитуре утрачена середина скрипичного голоса.

Это reverse-задача с музыкальной VM: бас выбирает область памяти,
фортепиано предоставляет разрешения, скрипка задаёт вычисления, а длительности
нот определяют сроки их выполнения. Участник восстанавливает середину
скрипичной партии по изображению и бинарю. Проверка требует исходные
времена нот и неизменное сопровождение. Эталонные 173 ноты сохранены.

## Решение

Из финального сравнения в бинаре извлекается EXPECTED: двенадцать uint192.
Из проверки партитуры извлекаются времена нот и известные края скрипичной
партии. Таблица находится по последовательности нот публичного сопровождения.
Эти данные определяют адресацию всех операций скрипки.
Каждая нота исполняет пять операций ADD над парой положительных ячеек.
Большая ячейка показывает направление последнего сложения; вычитание
восстанавливает его операнды. Обращая все операции от конца к началу,
получаем пятибитные слова и однозначно восстанавливаем высоты.
Затем сериализуем ноты в ABC и отправляем три партии серверу.

[Подробный разбор](solve/solve.md), [скрипт решения](solve/solve.py).
Python 3.10+, внешних зависимостей нет. Запуск из корня задания:

```sh
python3 solve/solve.py --output /tmp/recovered.abc --url http://127.0.0.1:9898
```
