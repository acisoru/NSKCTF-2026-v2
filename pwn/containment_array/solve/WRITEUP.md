# Контур памяти — разбор для автора

## Поверхность

`VIEW` считает допустимыми индексы 0–31, потому что спецификация контроллера описывает 32 логических канала. В функции `inspect_channel` массив `sensors` содержит только 8 элементов. Значения за его концом печатаются как 64-битные слова стека.

| Индекс | Значение в поставляемом бинаре |
|---|---|
| 9 | stack canary |
| 11 | адрес возврата `main+0x15a`, абсолютный адрес `PIE+0x16ab` |
| 31 | адрес возврата в libc, `libc+0x2724a` |

Базы PIE и libc вычисляются вычитанием указанных смещений. Последний адрес соответствует инструкции после вызова `main` в libc. В разных соединениях ASLR меняет адреса; все три утечки надо взять из того же соединения, в котором отправляется кадр.

## Переполнение

В `calibrate_frame` 96-байтный массив расположен по адресу `rbp-0x70`. Канарейка находится по `rbp-0x8`. До неё 104 байта, затем 8 байт канарейки, 8 байт сохранённого `rbp` и адрес возврата. Команда `CAL <length>` читает точно указанное число байт, включая нули, поэтому ROP цепочку можно передать как бинарный кадр.

Секкомп фильтр запрещает `execve`, `execveat` и системные вызовы x32. Полный RELRO закрывает перезапись GOT, NX не даёт выполнить код на стеке. Предполагаемый путь — ROP с разрешёнными файловыми вызовами.

## Цепочка

В предоставленной libc есть гаджеты `pop rdi; ret`, `pop rsi; ret`, `pop rdx; ret`. Через них вызываются:

1. `open(PIE+flag_path, O_RDONLY)`;
2. `read(3, PIE+.bss, 0x100)`;
3. `write(1, PIE+.bss, 0x100)`.

В начале процесса закрываются все дескрипторы от 3 до 63, унаследованные от TCP слушателя. Поэтому `open` предсказуемо возвращает дескриптор 3. Перед первым вызовом libc добавлен одиночный `ret` для выравнивания стека.

Проверка: `python3 solve/solve.py <ip> 34120`.

После флага файл содержит строку `УЛИКА:`: изолированный массив датчиков регистрировал питание в 559 суток без журнала ALICE. Для CTFd она дублируется в бесплатной подсказке задания.
