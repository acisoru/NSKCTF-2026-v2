# Контур памяти | Medium | pwn

## Информация

> После ревизии ALICE открыла доступ к карантинному контуру собственной памяти. В установке сохранилось восемь физических датчиков, но контроллер по-прежнему принимает запросы к тридцати двум каналам. Он также принимает калибровочные кадры, хотя никто уже не помнит допустимый размер старого буфера.
>
> Восстановите запись из изолированного контура. Оболочка вам не поможет.
>
> TCP: `<ip>:34120` (`nc <ip> 34120`)
>
> 3D пульт и браузерный терминал: `http://<ip>:34121`

## Деплой

```sh
cd deploy
docker compose up --build -d
```

Два контейнера: нативный TCP сервис и 3D пульт с WebSocket мостом к нему. Каждый TCP/браузерный сеанс запускает отдельный процесс. Файл флага хранится только в нативном контейнере. Деплой запускает бинарь и libc из `public/` через поставляемый загрузчик, поэтому участники получают ровно те же артефакты, что стоят на сервере. При изменении `src/native/chamber.c` публичный бинарь нужно пересобрать до деплоя.
Для сборки на сервер достаточно скопировать только `deploy/`; её копии `public/` и `src/visual/` обновляются командой `python3 scripts/sync_task_deploy.py` из корня репозитория.

## Выдать участникам

Файлы из [public/](public/): `chamber`, `libc.so.6`, `ld-linux-x86-64.so.2`; TCP адрес и URL пульта. Эти же файлы доступны для скачивания из пульта.

## Описание

Нативная Linux x86-64 задача сложности Medium для турнира с высоким уровнем участников (ориентир Hard+). Карантинный контур — изолированная часть ALICE, оставшаяся после цикла «HACKED»; её телеметрия относится к годам, которых нет в журнале наблюдения. Физический массив содержит 8 значений, а обработчик `VIEW` проверяет индекс по числу логических каналов (32). Запросы к индексам 8–31 читают стек за массивом. Обработчик `CAL` принимает до 512 байт в 96-байтный буфер. Бинарь собран с PIE, полным RELRO, NX и stack canary. Seccomp блокирует `execve`/`execveat`; завершение требует ROP-цепочки чтения файла. 3D-модель установки показывает восемь датчиков; браузерный терминал позволяет читать их значения, а эксплуатация доступна и напрямую по TCP.

## Решение

1. `VIEW 9` раскрывает stack canary, `VIEW 11` — адрес возврата в PIE, `VIEW 31` — адрес возврата внутри libc. Смещения относительно предоставленных бинаря и libc приведены в [разборе](solve/WRITEUP.md).
2. Сформировать кадр `CAL` длиной до 512 байт: 104 байта заполнения, правильная канарейка, сохранённый `rbp`, затем ROP.
3. Использовать гаджеты libc для `open("/srv/chamber/flag.txt", 0)`, `read(3, .bss, 0x100)`, `write(1, .bss, 0x100)`. Дополнительные дескрипторы закрываются перед сеансом, поэтому `open` возвращает 3.
4. Получить флаг и строку `УЛИКА:` из файла: изолированный массив датчиков регистрировал питание во время пробела в журнале.

[Автоматический эксплоит](solve/solve.py). Для запуска требуется `pwntools` из [requirements.txt](solve/requirements.txt).
