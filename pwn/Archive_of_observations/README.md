>

## Деплой

```sh
cd deploy
docker compose up --build -d
```

## Выдать участникам

Только URL и порт сервера.

## Описание

Веб-дашборд лаборатории с журналами, персоналом, карантином, отчётами и настройками. Среди
безопасных полей ввода спрятана настройка отображения панели, которая передаёт строку состояния
в нативный форматтер. Пароль оператора лежит в heap-буфере форматтера; `fprintf` вызывается без
variadic-аргументов.

## Решение

1. Изучаем `/settings` → «Настроить отображение панели» → `/settings/appearance`.
2. Проходим CAPTCHA. После успешной проверки сессия помечается как операторская на несколько
   минут; для нового запроса можно запросить новый код.
3. В поле «Строка состояния» отправляем `A%N$n`, перебирая N. При попадании в указатель на
   управляющий флаг вывод станет `A`, а следом появится пароль оператора:

   ```text
   A
   <32-символьный пароль>
   ```

   `A` нужен, чтобы `%n` записал ненулевое число. Точное смещение зависит от сборки;
   Прямой перебор `%N$s` пароль не возвращает.
4. Откроем `/login`, получим CSRF-токен и войдем как `operator` с найденным паролем.
5. После входа откроем `/vault` — там флаг.

CAPTCHA реализована сервером: PNG 190×64, одноразовый код, TTL 120 секунд, привязка к сессии.
Для локального чекера можно включить тестовый bypass через `PWN_CAPTCHA_TEST_TOKEN`; в боевом
`.env` он не задаётся.

[Автопывн](solve/solve.py)

```sh
cd deploy
PWN_CAPTCHA_TEST_TOKEN=local-check docker compose up --build -d
cd ..
PWN_PORT=18110 PWN_CAPTCHA_TEST_TOKEN=local-check python3 solve/solve.py
```
