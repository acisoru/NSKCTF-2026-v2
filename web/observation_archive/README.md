Для сборки на сервер достаточно скопировать только `deploy/`; её копия `src/` обновляется командой `python3 scripts/sync_task_deploy.py` из корня репозитория.

## Описание

Интерактивная 3D-комната архива ALICE с журналом инцидентов, калибровочным пультом и закрытым разделом. Игрок создаёт CSS для контрольного оттиска и отправляет его на служебную проверку. Страница проверки содержит короткий случайный ключ в атрибуте элемента; CSP запрещает JavaScript и внешние обращения, но разрешает локальные изображения для диагностики. Запечатанная запись различает пустое поле оператора и затёртое.

## Решение

1. Калибровочный пульт принимает CSS и запускает проверку в браузере сотрудника. Страница просмотра содержит атрибут `data-access-key` на `body`.
2. Подобрать очередной шестнадцатеричный символ ключа с помощью CSS селекторов по префиксу: `body[data-access-key^="a"] { background-image: url('/api/telemetry?probe=a'); }`. Нужно отправить 16 таких правил для очередного символа.
3. Только совпавший селектор заставит браузер сотрудника запросить локальный диагностический пиксель. Результат виден владельцу слепка через `/api/plates/<id>/telemetry`. Повторить для всех 12 символов.
4. Передать ключ в `/api/archive?key=<key>`, получить флаг и сюжетную улику.
