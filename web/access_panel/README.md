## Описание

Старая панель допуска 2018 года, разложенная по нескольким страницам: главная со списком бейджей, журнал выдачи карт с сортировкой по клику, лента оповещений отделения, техподдержка и отдельная страница входа для сотрудников. Цель участника — войти в панель оператора и прочитать примонтированный архив с файлом, где содержится флаг.

## Решение

Коротко: **SQLi в сортировке журнала → логин оператора → path traversal в экспорте файлов → флаг.**

1. **Достаём логины и пароли из БД.** На странице `/journal` клик по заголовку колонки шлёт `POST /archive/access-log` с параметром `sort`. Сервер вставляет его прямо в `ORDER BY` без проверки — это единая точка инъекции, она не привязана к конкретному полю. Ошибок в ответе нет — страница всегда выглядит одинаково, поэтому извлекать данные приходится вслепую: либо по задержке ответа (time-based, через `pg_sleep` внутри `CASE WHEN`), либо по видимому порядку строк в JSON-ответе (boolean-based, без задержек вообще). Через `information_schema` находим таблицу `staff`, затем вытаскиваем из неё все три пары логин:пароль — посимвольно по ASCII-коду символа.
2. **Находим, у кого есть доступ к панели.** В `staff` три учётки, но какая из них — оператор, в БД никак не помечено. Логинимся по очереди под каждой (все три входят честно) и смотрим на `/panel`: у двух «Недостаточно допуска», у `night_shift` — «Экспорт протокола».
3. **Выходим за пределы папки экспорта.** `GET /panel/export?file=...` отдаёт файлы из каталога выгрузок. Защита проверяет только явный `../` и убирает его один раз, не рекурсивно — поэтому `....//` после одной такой чистки снова превращается в `../`.
4. **Читаем /proc/mounts и находим флаг.** Этим же способом читаем `/proc/mounts`, видим, что в контейнер смонтирован архив лаборатории (`/var/lib/labx/archive`), и читаем из него `ledger.txt` (имя файла указано в примечании оператора на `/panel`) — запись о входе по допуску 000 с флагом внутри.

Полный разбор по шагам — в [solve/solution.md](solve/solution.md), готовый эксплойт — в [solve/solver.py](solve/solver.py).
