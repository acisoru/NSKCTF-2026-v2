# DON'T PRESS | Easy | web

## Информация

> На пульте аварийного контура стоит кнопка. На ней написано, что с ней делать.
>
> mr. S восемь лет жмёт на всё, до чего дотягивается. Дотянитесь до этой.
>
> http://<ip>:63391

## Деплой

```sh
cd deploy
docker-compose up --build -d
```

Контейнер слушает `127.0.0.1:63391`, наружу выводится через nginx с доменом. Состояния на сервере нет, счётчик живёт в cookie игрока.

## Выдать участникам

Только URL.

## Описание

Первое знакомство с инструментами разработчика в браузере. Три слоя защиты, и все три стоят на стороне клиента. Сервер хранит ноль и верит тому, что прислали.

Улика: `mr. S`. Карта третьего уровня, дверь второго контура. Кнопку он нажал, серверную не открыл (`LEGEND.md` §4.3).

## Решение

1. **`disabled`.** В инспекторе убрать атрибут у `<button id="press">` и нажать.
2. **Кнопка убегает от курсора.** Обработчик слушает только мышь: Tab и Enter нажимают кнопку спокойно. Подойдёт и `document.getElementById('press').click()` в консоли. Поймать нужно три раза.
3. **Счётчик на 1000 нажатий с паузой 3 секунды.** Пауза есть только в JavaScript, число нажатий лежит в cookie `presses`. Подойдёт любой из способов:
   - выставить `presses=999` в DevTools и нажать ещё раз;
   - в консоли: `for (let i = 0; i < 1000; i++) await fetch('/api/press', {method: 'POST'})`, затем обновить страницу;
   - `curl -X POST -b 'presses=1000' http://<ip>:63391/api/press`.

[Скрипт решения](solve/solve.py): `python3 solve/solve.py http://<ip>:63391`.

Слои можно пропустить через cookie или curl сразу. Это тоже решение и суть задачи.
