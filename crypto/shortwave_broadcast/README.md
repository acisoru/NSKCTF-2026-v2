# Три копии | Easy | crypto

## Информация

> ALICE выгрузила один и тот же фрагмент архива на три удалённых узла Лаборатории X. У каждого узла свой ключ RSA, но прошивка радиоканала экономила время на паддинге. Восстановите радиограмму и найдите код доступа.


## Деплой

Деплой отсутствует. Публичный файл выдаётся участникам через CTFd.

## Выдать участникам

[public/broadcast.json](public/broadcast.json). Каталоги `src/` и `solve/` не выдавать.

## Описание

Три независимых 1024-битных модуля RSA шифруют одинаковую радиограмму с открытой экспонентой 3. Паддинг не используется. Сообщение достаточно длинное, чтобы нельзя было извлечь кубический корень из одного шифртекста, но его куб меньше произведения трёх модулей.

## Решение

Модули попарно взаимно просты. Китайская теорема об остатках восстанавливает `m³` по трём шифртекстам в диапазоне от нуля до `N₁N₂N₃`. Так как `m³ < N₁N₂N₃`, результат равен настоящему кубу сообщения. Остаётся извлечь точный целочисленный кубический корень и декодировать UTF-8. Это широковещательная атака Хостада на RSA без паддинга. В строке `КОД` лежит флаг, в строке `ПРОБЕЛ` — сюжетная улика.

[Скрипт решения](solve/solve.py): `python3 solve/solve.py`.
