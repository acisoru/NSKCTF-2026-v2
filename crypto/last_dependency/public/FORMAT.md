# Формат реестра ALICE

Каждый сетевой экземпляр и локальный `sample.bin` используют группу Ristretto255. `G` — стандартная базовая точка группы; порядок группы равен

`2^252 + 27742317777372353535851937790883648493`.

Все точки записаны в стандартной 32-байтной сжатой форме Ristretto255. Скалярные значения — по 32 байта в порядке **little endian**, приведённые по модулю порядка группы. Целые `u32` также записаны в порядке little endian.

| Поле | Размер | Значение |
|---|---:|---|
| magic | 8 | ASCII `LABXRLG1` |
| version | u32 | `1` |
| size | u32 | Число точек в каждой из четырёх таблиц |
| Q | 32 | Открытая точка `[d]G` |
| points | `4 × size × 32` | Четыре таблицы по порядку, глобальный номер `table × size + index` |
| edges | `(4 × size − 1) × 72` | Записи дерева в произвольном порядке: `child:u32`, `parent:u32`, `u:scalar`, `v:scalar` |
| target_u | 32 | Скаляр `u` последней записи |
| target_v | 32 | Скаляр `v` последней записи |
| target_point | 32 | Точка последней записи |
| nonce | 24 | XChaCha20-Poly1305 nonce |
| sealed_length | u32 | Длина зашифрованной записи с тегом |
| sealed | sealed_length | В локальном образце — шифртекст XChaCha20-Poly1305 с 16-байтным тегом; в сетевом экземпляре длина равна нулю |

Для каждого ребра выполняется

`A_child − A_parent = [u]G + [v]Q`.

Последняя запись имеет четыре отсутствующих номера, по одному из каждой таблицы. Для них выполняется

`A_(0,i) + A_(1,j) − A_(2,k) − A_(3,l) = [target_u]G + [target_v]Q = target_point`.

Ключ записи: `SHA256(b"LABX/ALICE/RELATION-LEDGER/2026\x00" || d.to_bytes(32, "little"))`. Дополнительные аутентифицируемые данные AEAD — восемь байт `LABXRLG1`.

## Сетевой протокол

Сразу после подключения сервер отправляет длину нового реестра как `u32` **big endian**, затем ровно столько байт реестра и текстовую строку приглашения. На ответ даётся **888 секунд** с момента отправки реестра. Отправьте `d.to_bytes(32, "little").hex()` и символ новой строки. При правильном ответе сервер выдаст флаг и улику. Сетевой реестр не содержит шифртекста: запись выдаётся только после ответа. Каждое подключение получает новый реестр.

`sample.bin` содержит маленький локальный образец с тестовым флагом. Он нужен для проверки парсера и решателя; его размер таблицы отличается от турнирного.
