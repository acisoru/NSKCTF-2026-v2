    Как читать карту

    NIGHTLINE — ночной диспетчерский тренажёр из карантинного архива ALICE. Перед тобой условный город, не план лаборатории. Начальные координаты курьеров неизвестны; общий канал уцелел.

    R

    Проехать по красной сплошной дороге из текущего узла, следуя стрелке.

    B

    Проехать по синей пунктирной дороге из текущего узла, следуя стрелке.

    • В каждом узле ровно один выезд каждого цвета. Одна команда — один переход, независимо от длины дороги.
    • Соединения существуют только в пронумерованных узлах. Пересечение линий вне узла не является перекрёстком.
    • Петля возвращает в тот же узел. Повторять узлы и дороги разрешено.
    • Склад отмечен зелёным. Он тоже может быть начальной точкой и тоже имеет выезды.
    • Курьер выполняет всю строку, даже если уже заехал на склад. На складе нужно оказаться после последней команды.
    • Одна и та же строка должна работать из всех 20 узлов. Максимум — 128 команд. Кратчайший маршрут искать необязательно.

    Карту можно приближать, разделять по цветам и скачивать. Блокнот, маршрут и пометки сохраняются в этом браузере. Сессия действует 48 часов.
