# Ревизия: карантин | Easy | misc

## Информация

> Периметр цел. Заражение поднялось изнутри.
> ALICE открывает мир лаборатории: торговые посты, сервисные дворы,
> архив, нестабильный контур и ядро карантина.
> Соберите отряд, найдите снаряжение и доберитесь до Стража.
>
> http://<ip>:3387
>
> Первые два рейдовых босса дают персональные допуски. Последний открывает
> архив с флагом участникам отряда, нанёсшего последний удар.
> Вне зелёных контуров разрешён PvP.

## Деплой

Исходники для разработки находятся в `src/`. Каталог `deploy/` содержит
копию `src/`, Dockerfile, Compose-файл и `.env`. Для сборки достаточно
самого каталога `deploy/`.

```sh
cd misc/quarantine/deploy
docker compose up
```

Команда выше выполняется из корня репозитория; если вы уже в `deploy/`, достаточно
`docker compose up`. Compose автоматически читает `.env` рядом с compose-файлом
и собирает сервер и клиент из `deploy/src/`. Node.js и npm
на хосте не нужны. `pull_policy: build` обновляет образ при обычном `up`, поэтому
после изменения исходников не требуется отдельно указывать `--build`.
Для фонового запуска: `docker compose up -d`. Ctrl+C при обычном запуске штатно
останавливает игру; персонажи, сессии и баны остаются в именованном volume.

Только при первом развёртывании на другой машине: создать `deploy/.env` из
`deploy/.env.example`, заполнить `FLAG`, `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`,
`PUBLIC_ORIGIN` и при необходимости `ADMIN_YANDEX_IDS`, затем выполнить
`chmod 600 .env` из `deploy/`. Уже настроенный `.env` не перезаписывать.
Файл с секретами не хранится в Git. После изменения исходников для разработки
выполните `./deploy/sync-src.sh` из каталога задачи; только после синхронизации
новая версия попадёт в следующую Docker-сборку.

Один процесс Node.js 24+, лимит 300 одновременных персонажей в общем мире,
отряды до десяти игроков, включая создателя. Docker ограничен 4 CPU / 8 GB RAM.
Физика и бой: 30 фиксированных шагов/с; WebSocket-снимки: до 10/с.
Общие дельты мира сжимаются один раз на пространственную ячейку; инвентарь,
личная добыча и награды идут отдельно только владельцу. Медленные клиенты
пропускают снимки и затем получают полный; ввод и объём сообщений ограничены.
Сетевой UX использует безопасную prediction/reconciliation-схему: клиент каждый
кадр предсказывает только отображение собственного движения и интерполирует
удалённых игроков/врагов, поэтому задержка WebSocket не останавливает камеру.
Сервер остаётся источником истины: его фиксированная физика проверяет скорость,
стены, лестницы, прыжки, высоту, урон, боезапас, перезарядку и награды. Небольшое
расхождение плавно сводится к серверному снимку; респавн, телепорт или крупная
ошибка применяются сразу. Клиентские эффекты, recoil и prediction не могут
изменить игровой результат.

В Docker с лимитом 4 CPU / 8 GB проверены 300 настоящих WebSocket-клиентов.
Повторный 30-секундный прогон: 29.4-29.7 шагов/с, без отключений и пропущенных
снимков, но p99 шага в распределённом бою 39.58 мс при бюджете 33.34 мс.
Этот прогон не прошёл порог производительности; требование «300 без лагов»
пока не подтверждено. Предыдущий короткий прогон укладывался в бюджет.
Исходящий payload достигал 367 Мбит/с; рекомендуется канал 1 Гбит/с с запасом.
Игровая симуляция однопоточная: 4 CPU не означают четыре параллельных цикла мира.
Нужны профилирование и длительный прогон на целевом VPS с внешними клиентами.
[Методика, оба результата и повторный запуск](src/tests/LOAD_RESULTS.md).

Прогресс сохраняется раз в 10 секунд и при штатном завершении процесса в
`/app/data/players.json`. Запись атомарна, через временный файл и rename.
Docker использует именованный volume `quarantine_progress`. Сохраняются позывной,
класс, уровень, опыт, здоровье, валюта, аптечки, предметы с боезапасом, экипировка,
допуски, идентификатор Яндекса и право на флаг.
После перезапуска персонажи входят через поселение; составы отрядов, позиции,
состояние врагов и лежащая на земле добыча не сохраняются.
Не удалять volume при обновлении. При аварийном выключении возможна потеря
последних десяти секунд прогресса. Повреждённое хранилище останавливает запуск,
а не обнуляется автоматически.

Вход только через Яндекс OAuth. В приложении Яндекса задать право `login:info`
и точный Redirect URI: `http://localhost:3387/auth/yandex/callback`.
Локальный `PUBLIC_ORIGIN` равен `http://localhost:3387`; открывать игру именно
по этому адресу, а не через другой hostname. Для публикации заменить origin
и Redirect URI на публичный HTTPS-домен. Секрет находится только в серверном
окружении; `.env` исключён из Git и Docker build context.

Поток использует одноразовый state, привязку к браузеру и PKCE S256. Игровая
сессия хранится в HttpOnly / SameSite=Lax cookie (Secure на HTTPS), её хеш
сохраняется в `auth-sessions.json`, срок жизни 7 дней. Токен доступа Яндекса
не сохраняется. Один Yandex ID связан с одним персонажем; повторный вход,
очистка браузера и смена устройства не дают нового стартового набора.
Это ограничение аккаунтов, а не доказательство «один человек»: человек с
несколькими аккаунтами Яндекса может получить несколько персонажей.
Вторая вкладка перехватывает активное игровое соединение этого персонажа.

Старый персонаж переносится при первом входе, если браузер сохранил прежний
локальный токен. Миграция требует авторизованной сессии и доступна один раз
до регистрации нового персонажа; для старого профиля с другого hostname
автоматический перенос не сработает. Резервировать volume и защищать от чтения.
Хранилище персонажей содержит право на награду, но не строку флага.

Локально, из каталога `misc/quarantine/src/`:

```sh
npm ci
npm run dev
# http://localhost:3387
```

Без `FLAG` создаётся случайный локальный preview-флаг; в production отсутствие
`FLAG` останавливает запуск. Настройки: `PORT` (3387), `HOST` (127.0.0.1 локально),
`DATA_DIR` (`./data` локально), `MAX_PLAYERS` (300), `PUBLIC_ORIGIN`,
`YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`. `npm start` читает `../deploy/.env`.
Без OAuth-данных вход закрыт. Анонимный режим существует только в тестовой
фикстуре, не включается переменной окружения и запрещён в production.
Публиковать через HTTPS с поддержкой WebSocket, передавать исходный `Host`.
Origin браузера должен совпадать с `PUBLIC_ORIGIN`. Таймаут прокси не менее 60 секунд.
Сервер не доверяет `X-Forwarded-For`: лимит 900 новых соединений в минуту
применяется к адресу непосредственного соединения, то есть к прокси, если он есть.
Настроить этот лимит и ограничения прокси под ожидаемую аудиторию.
Независимые реплики образуют независимые миры; общий JSON-файл нельзя разделять
между процессами. Для масштабирования требуется отдельная архитектура.

Проверки из каталога `src/`:

```sh
npm run build
npm test
node ../solve/simulate.mjs
npx playwright install chromium
npm run test:browser
npm run test:models
npm run test:recreate
npm run test:admin-browser
npm run test:load
```

Браузерная проверка поднимает отдельный сервер на свободном порте, открывает
два PC-контекста и сохраняет скриншоты в `src/test-results/`.
Установленный Google Chrome на macOS может использоваться вместо загруженного
Chromium. Реальный OAuth consent проверяется вручную в браузере; автотесты
используют подменённые ответы провайдера, не личный аккаунт организатора.

Администраторы задаются только на сервере: `ADMIN_YANDEX_IDS=123456,789012`
в `deploy/.env`. Это личные идентификаторы пользователей Яндекса, не Client ID
OAuth-приложения и не позывные. По умолчанию список пуст, администраторов нет.
После изменения списка пересоздать контейнер. Права нельзя получить через
клиентский флаг, localStorage, ник или вход первым игроком.

У администратора в игре появляется кнопка со щитом. Панель содержит список
игроков, поиск по имени/игровому ID, карту всего мира, фильтр блокировок,
наблюдение, переключатели полёта и админ-пушки «Инспектор».
В полёте WASD перемещает горизонтально, Space поднимает, Ctrl опускает,
Shift ускоряет. Администратор неуязвим, проходит препятствия и не привлекает
противников. Высота ограничена 80 м, координаты границами карты.
Наблюдение следует за выбранным игроком; кнопка перечёркнутого глаза возвращает
свободный полёт. Выключение режима и отключение возвращают администратора
в точку включения, без бесплатного лечения. Режим не сохраняется между запусками.

«Инспектор» доступен только в активном админ-режиме: одно попадание убивает
игрока или врага, но стены, зелёные зоны и неуязвимость после эвакуации защищают.
Во время наблюдения оружие заблокировано. Пушка не является предметом инвентаря
и не даёт опыт, валюту или флаг. Вмешательство в босса, его генераторы или
подкрепления отключает награды всего этого боя до сброса/возрождения босса.
Администратор в режиме полёта также не получает награды за чужие убийства.

Бан привязан к Yandex ID, немедленно отключает игрока, отзывает игровые сессии
и запрещает повторный OAuth-вход на срок 1 час, 24 часа, 7 дней или бессрочно.
Причина обязательна; перед действием есть подтверждение. Снять бан можно
в фильтре «Заблокированные»; после снятия нужен новый вход. Других администраторов
и себя заблокировать через панель нельзя. Новый аккаунт Яндекса не связан со
старым баном: это не блокировка человека по устройству или IP.

Баны и последние 500 действий модерации атомарно сохраняются в
`/app/data/moderation.json`, в том же volume. Не удалять этот файл при обновлении.
`GET /api/admin/players` и `POST /api/admin/moderate` требуют активной OAuth-сессии
администратора; POST дополнительно проверяет Origin. Список возвращает до 50
записей на страницу и не раскрывает токены или Yandex ID игроков браузеру.

## Выдать участникам

URL сервиса. Сервер, `.env`, хранилище, исходники тестов и авторское решение
не выдавать. Сервер отдаёт статический клиент, `/healthz`, `/api/session`,
`/auth/yandex`, `/auth/yandex/callback`, `/auth/logout`, `/auth/migrate`, `/ws`
и закрытые для участников `/api/admin/players`, `/api/admin/moderate`.
В клиентской сборке флага нет.

## Описание

Общий 3D-мир по мотивам ноябрьской «РЕВИЗИИ» из `LEGEND.md`.
Размер около 481 × 525 игровых метров: площадь в десять раз больше начального
прототипа. В мире 60 зданий, три торговых поселения, 75 точек появления обычных
врагов и 12 патрульных дронов-подрывников.
Камера от первого лица находится на уровне глаз; собственная модель скрыта,
перед игроком видны руки и выбранное оружие с отдачей и анимацией перезарядки.
Доступны полный горизонтальный обзор, взгляд вверх-вниз, крен и оптическое
приближение. Игра рассчитана на ПК. Мышь поворачивает камеру, колесо меняет угол
обзора без перемещения камеры, Z/C наклоняют горизонт, Home или кнопка камеры
возвращает обычное положение. Прыжки и лестницы изменяют высоту взгляда.
Руки рисуются отдельным проходом до CRT-эффекта и не проваливаются в стены;
серверные препятствия по-прежнему блокируют выстрелы. Во время подъёма оружие убрано.
Индустриальный комплекс: бетонные корпуса, трубопроводы, торговые посты,
туман, дождь, тени и CRT-постобработка: искривление экрана, строчная развёртка,
маска RGB-люминофора, движущаяся полоса развёртки, шум и хроматическое расхождение.
Интерфейс выводится поверх эффекта и остаётся чётким. Подробная модель штурмовика
с оружием содержит около 79 тысяч треугольников, Стража около 74 тысяч,
обычного дрона около 30 тысяч.
Статическая геометрия объединена по материалам и пространственным участкам,
удалённые динамические модели отсеиваются. Для ближайших 16 игроков используются
подробные модели, для остальных LOD. До 12 обычных противников в радиусе 45 м
рисуются подробно; более дальние используют облегчённые модели с сохранением
силуэта, индикаторов и анимации винтов. Боссы сохраняют подробную модель.
Внешние CDN и игровые ассеты во время игры не нужны.

Оружие имеет разные затворы, магазины, оптику, насечки, крепёж и маркировку;
на руках видны манжеты, швы и защитные накладки. Экипировка трёх ролей отличается
подсумками, медицинским комплектом и дополнительной бронёй. У дронов есть
панели корпуса, проводка, двигатели и вращающиеся вентиляторы. Архивариус несёт
кассеты архивных модулей, Резонатор оснащён катушками и резонансными элементами,
Страж носит броню с предупредительными полосами; у боссов вращается механизм центрального узла.
Ящики снабжения получили крышки, застёжки и защитные рёбра.

Материалы металла, ткани и окрашенных поверхностей используют локальные
растровые карты шероховатости и микрорельефа. Неподвижные детали объединены
по материалам, а суставы, оружие и вращающиеся элементы остаются независимыми.
Коллизии, области попадания, урон и сетевой протокол этим изменением не меняются.
[Проверки моделей и ограничения замеров](src/tests/MODELS.md).

Позиции приходят с сервера 10 раз в секунду. Клиент хранит короткую историю
и интерполирует движение и повороты на каждом кадре с буфером 150 мс, чтобы
избежать рывков между пакетами. При обрыве связи движение останавливается
на последней полученной позиции; телепорты и переподключения сбрасывают историю.
Обзор с мыши и клавиатуры обновляется на каждом кадре без этого буфера.

WASD перемещает персонажа, Shift включает бег с расходом выносливости, Space
прыгает. У лестницы E прикрепляет к ней, W/S поднимает и спускает; Space позволяет
отпустить лестницу. Крыши имеют серверные коллизии. Клиент не передаёт координаты
или собственное время шага; частота пакетов не увеличивает скорость движения.

Игроки исследуют мир, уничтожают возрождающихся противников, набирают опыт
до 12-го уровня, собирают персональную добычу и покупают снаряжение.
Есть три слота: оружие, броня, артефакт; четыре качества предметов.
Обычные противники возрождаются через 48 секунд. Рюкзак: 32 предмета,
аптечки: до 15. Аптечка восстанавливает 45% здоровья, перезарядка 12 секунд.
Торговля возможна только рядом с торговцем, с учётом высоты;
надетое снаряжение продать нельзя. Пассивного лечения нет ни в городе,
ни при повышении уровня, ни при повторном входе. H расходует аптечку;
способность медика также расходует одну аптечку. Полное здоровье выдаётся
новому персонажу и при эвакуации после смерти.

В снаряжении (I) есть кнопка «Пересоздать персонажа». В окне нужно выбрать
другую роль и подтвердить сброс. Сервер разрешает действие только живому
персонажу на земле в зелёной зоне, вне режима администратора, не чаще раза
в минуту. Персонаж возвращается в стартовое поселение с уровнем 1 и базовым
снаряжением; опыт, кредиты, прежние предметы, допуски и отряд сбрасываются.
Стартовые 50 кредитов повторно не выдаются, запас аптечек становится не больше
трёх и не увеличивается. Позывной, Yandex-аккаунт, бан и уже заслуженный флаг
сохраняются. Оставленные предметы и вклад в старые бои удаляются, старые
собственные снаряды отменяются. Повтор подтверждения отклоняется по ревизии,
которая сохраняется вместе с новым персонажем; успешный ответ отправляется
после записи сохранения. Автотесты используют отдельные тестовые аккаунты.

| Оружие | Магазин | Перезарядка, с | Дальность, м |
|---|---:|---:|---:|
| Пистолет | 12 | 1.35 | 48 |
| Винтовка | 24 | 1.8 | 65 |
| Дробовик (8 дробин) | 6 | 2.5 | 27 |
| Снайперская винтовка | 5 | 2.8 | 110 |
| Пулемёт | 60 | 3.3 | 62 |

R перезаряжает оружие; пустой магазин запускает перезарядку при попытке выстрела.
Запас патронов вне магазина не ограничен. Смена оружия не сбрасывает задержку
выстрела и не пополняет магазин. Различаются разброс, урон, скорость пули,
модель, звук и штраф к скорости движения.

Стрельба использует серверные трёхмерные снаряды с конечной скоростью, а не
мгновенный урон. Пули игрока летят со скоростью 48-150 м/с в зависимости от оружия;
попадания проверяются по всему отрезку движения каждого такта, чтобы не
пропускать стены или персонажей. Учитываются высота цели, земля, здания,
защита союзников от урона и безопасные зоны, поглощающие снаряды. Клиент показывает
металлические пули с остриём и коротким затухающим трассером, вспышки ствола,
отдачу и искры попадания; звуки выстрела
проигрываются только по серверным событиям, с расстоянием и стереопанорамой.

Обычные дроны стреляют очередями по три пули до 27 м, турели — по четыре до
31 м. Перед очередью есть короткая зарядка. Они держат дистанцию, смещаются
вбок и упреждают движение игрока; выстрелившего издали преследуют дальше.
Урон одной пули дрона — `14 + 3 * уровень`, турели — `18 + 4 * уровень` до
применения брони. Неподвижный игрок вне укрытия может погибнуть от одного дрона.
Параметры игроков вынесены в `WEAPONS`, противников в `GUNS` в `src/shared/config.mjs`.

Дроны-подрывники несут красную связку динамита и патрулируют над дорогами.
Их сектор обзора — 120 градусов на 16 метров, показан на земле и мини-карте.
Стены перекрывают обзор; игроки в поселениях, отключившиеся и погибшие не
становятся целями. После обнаружения дрон подаёт звуковой сигнал и готовится
0.9 секунды, затем пикирует со скоростью до 23 м/с в последнюю выбранную точку.
После запуска он не доворачивает за игроком. Можно уйти в сторону, спрятаться
за препятствием или сбить дрон до попадания. Пикирование имеет серверную высоту
для синхронной анимации; движение и столкновения по земле остаются серверными.

Взрыв имеет радиус 4.5 м, урон `65 + 7 * уровень` в центре со снижением к краям.
Стены и безопасные зоны защищают от урона. Самоподрыв не выдаёт опыт или добычу;
сбитый дрон даёт обычную награду. Возрождение — через 56 секунд.
Звук взрыва синтезируется локально через Web Audio: низкочастотный удар и шумовой
хвост, затухание с расстоянием до 65 м и стереопанорама. Один сетевой эффект
воспроизводится ровно один раз. Звук включается после первого действия игрока;
кнопка динамика отключает его и запоминает выбор.

| Класс | Базовое здоровье | Способность |
|---|---:|---|
| Штурмовик | 140 | Урон в радиусе 8 м, в том числе другим игрокам |
| Медик | 125 | Лечение себя и отряда в радиусе 9 м за одну аптечку |
| Защитник | 195 | Снижение урона отряду на 60% в радиусе 7 м на 5 с |

Три зелёных нейтральных контура: поселение «Периметр», торговый пост «Тихий»
и посёлок «Резерв».
Урон запрещён, если источник ИЛИ цель находится в безопасной зоне. Проверка
происходит в момент нанесения урона, включая отложенные атаки по площади.
Внутри зон здоровье само не восстанавливается. Нет физического расталкивания игроков.
Вне контуров включён PvP между разными отрядами и одиночными игроками.
Дружественный огонь внутри отряда отключён для пуль, способностей и админ-пушки.
Принадлежность к одному отряду проверяется сервером в момент нанесения урона.
При смерти теряется 10% кредитов; при убийстве игроком эта сумма переходит
победителю. Предметы, опыт и допуски сохраняются. Через семь секунд происходит
эвакуация в поселение. За убийства игроков опыт не начисляется.

| Рейд | Место | HP | Награда | Возрождение |
|---|---|---:|---|---:|
| Архивариус | Архив на северо-западе | 2500 | Первый допуск, редкий предмет | 180 с |
| Резонатор | Нестабильный контур на северо-востоке | 4200 | Второй допуск, эпический предмет | 220 с |
| Страж карантина | Северное ядро | 8200 | Флаг, улика, эпический предмет | 300 с |

У всех боссов три фазы с подкреплениями. У Резонатора и Стража два генератора:
щит поглощает 85% урона, генераторы восстанавливаются на 67% и 32% HP.
Страж принимает урон только от обладателей обоих предыдущих допусков.
Его перегрузка раз в семь секунд наносит растущий урон по арене: долгий бой
требует лечения, защиты и ресурсов. Через 130 секунд дополнительно усиливаются
обычные атаки. HP не уменьшается для одиночного игрока. Боссы и их подкрепления
принимают урон только от игроков внутри радиуса агрессии 30 м от центра арены.
При потере всех целей
и отсутствии вклада более десяти секунд босс восстанавливается, вклад сбрасывается.

Флаг получает только отряд, участник которого нанёс финальному боссу последний
смертельный удар. Состав фиксируется сервером в момент смерти босса; вступление
в отряд после победы не даёт награды. Одиночный добивший игрок считается своим
отрядом из одного человека. Нанесённый чужим отрядом больший урон не даёт ему флаг.

Внутри победившего отряда награждаются только участники с обоими допусками, кто в этом бою
нанёс не менее 2.5% максимального HP босса (минимум 80) ИЛИ получил 100 очков
поддержки. Учитываются фактическое лечение других игроков и предотвращённый
урон по союзникам. Последний вклад должен быть не более 65 секунд назад.
Личный последний удар не обязателен, но его должен нанести кто-то из отряда.
Членство в отряде само по себе прав не даёт;
раненые и временно отключившиеся участники с достаточным вкладом не исключаются.
Опыт, предметы и допуски остальных боссов по-прежнему зависят от личного вклада;
обычная добыча финального босса также доступна остальным подходящим участникам,
но не флаг. Права персональны, не могут быть получены одним лишь чужим кодом
отряда и переживают перезапуск.
Передачу уже полученного обычного CTF-флага другим людям игра предотвратить не может.

ALICE наблюдает, автономные системы карантина охраняют области. Настоящие
причины инцидента, имя владельца допуска 000 и закрытые уровни 3/4 легенды
не раскрываются. Персональная улика относится к уровню 2.

Это игровой Easy Misc. Путь к флагу — исследование и рейды; эксплуатация
уязвимости не требуется. Автоматизацию сетевого управления исключить нельзя.
Сервер проверяет игровые правила, а не «человечность» игрока. Серверная проверка
защищает от подмены скорости, координат и ресурсов, но не гарантирует отсутствие
aimbot, ботов или всех возможных уязвимостей. Перед турниром нужен плейтест.
