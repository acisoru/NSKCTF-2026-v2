## Деплой

Статическая задача, сервер и порты не нужны. Готовая выдача лежит в `public/`.
`deploy/` содержит только необязательный контейнер пересборки:

```sh
docker compose -f misc/privet/deploy/docker-compose.yml run --build --rm privet_builder
```

Локальная сборка и проверка из корня репозитория, Python 3.13:

```sh
python3 -m venv /tmp/privet-venv
/tmp/privet-venv/bin/pip install -r misc/privet/requirements.txt
/tmp/privet-venv/bin/python misc/privet/src/build.py
/tmp/privet-venv/bin/python misc/privet/solve/solve.py
/tmp/privet-venv/bin/python -m unittest discover -s misc/privet/solve -p 'test_*.py' -v
```

Последний тест проверяет совместимость с независимым `npiet`, если задан
`NPIET=/полный/путь/к/npiet`. Сборка интерпретатора описана в
[разборе](solve/WRITEUP.md#проверка-независимым-интерпретатором).
Пиксели программы и байты капсулы воспроизводимы. Сжатие PNG может отличаться
между платформами из-за разных версий zlib внутри Pillow; тест сравнивает
точные RGB-значения. Ключевые байты и seed'ы выбраны независимо и сохранены
только в авторском исходнике.

## Выдать участникам

Все четыре файла из [public/](public/):

- [privet.png](public/privet.png) - программа Piet;
- [quarantine.bin](public/quarantine.bin) - шифрованное вложение;
- [terminal.txt](public/terminal.txt) - паспорт ввода;
- [unpack.py](public/unpack.py) - парсер и клиент расшифровки контейнера.

Структура контейнера задана кодом `unpack.py`: заголовок, nonce, шифротекст
и тег имеют отдельные имена. Запуск: `python3 unpack.py quarantine.bin key.txt`.
В `key.txt` должны быть 24 десятичных байта, разделённых пробелами.
Для запуска достаточно зависимости `cryptography==46.0.5`.

PNG выдавать исходным файлом: ресайз, JPEG, изменение палитры и цветокоррекция
ломают код. Ничего из `src/`, `solve/`, `deploy/` и этого README в выдачу
не включать. `build_public.sh` к авторским исходникам здесь не применяется:
замена текста флага не удаляет секретный ключ.

## Описание

Настоящий Piet со стандартной палитрой и codel size 1. Программа здоровается,
читает 24 байта в десятичной записи и печатает `1` только при правильном вводе.
Диапазон 0..255 проверяется отдельно. Флаг в выводе программы отсутствует.

Проверка содержит 480 обратимых нелинейных обновлений состояния в поле
F_257 и 40 перестановок, величина которых зависит от самого состояния.
Стековые обращения развёрнуты в `roll`, константы собраны арифметически,
площади цветовых блоков не равны длинам горизонтальных отрезков.
Белые переходы сбрасывают цвет между инструкциями, DP ведёт код змейкой,
а CC меняется по данным. В полезной программе 53 546 инструкций без
поворотных вставок компилятора.

Ключ капсулы: SHA-256 от исходных 24 байтов; содержимое защищено
ChaCha20-Poly1305. Обход сравнения даёт лишь квитанцию, а для извлечения
флага всё равно нужен ключ. Известный формат флага не позволяет восстановить
его простым XOR с шифротекстом.

Расчётная сложность Hard связана с подъёмом Piet в промежуточное представление
и поиском обратимости перестановки. Это не гарантия против решения агентом:
после распознавания конструкции автоматическое обращение быстрое.
Перед игрой полезен слепой плейтест, отдельно человеком и агентом.

### Канон и улика

Вводный текст соответствует открытому архиву ALICE. Расшифрованное вложение
даёт улику уровня 2, тип «ДОПУСК», в соответствии с §4.2–4.4 `LEGEND.md`.
Личность, судьба и мотив автора метки не раскрываются.

Строка для бесплатной подсказки CTFd, стоимость 0, и страницы «ДЕЛО»:

> Метка HACKED содержит маршрут в наблюдательную, вне покрытия камер,
> и номер допуска 000. В таблице этот допуск помечен «резервный, не выдан».

Добавить улику при открытии соответствующей игровой волны; не публиковать
в анонсе до игры. Эта же строка находится внутри капсулы рядом с флагом.

### Технические подсказки

Выдавать отдельно от сюжетной улики, по необходимости:

1. «Палитра здесь является набором команд. Белый цвет прерывает переход».
2. «`roll` иногда копирует значение, а иногда меняет весь порядок стека».
3. «Сумма элементов не меняется при циклическом сдвиге. А умножение на
   ненулевое число по модулю 257 обратимо».

## Решение

[Полный разбор](solve/WRITEUP.md), [решатель по публичным файлам](solve/solve.py),
[интерпретатор с трассировкой](solve/piet.py), [проверки](solve/test_challenge.py).

Решатель не импортирует генератор, не знает секретных seed'ов и не содержит
вшитого ключа или флага. Он извлекает операции и контрольное состояние из PNG,
обращает их, повторно исполняет картинку с восстановленным вводом и проверяет
тег капсулы перед выводом результата.
